# Epic 14.28 — Evidence: Browser Compatibility Matrix

**Baseline:** Chromium only (Playwright)

## Current State
- Playwright projects: `[{ name: "chromium", use: { ...devices["Desktop Chrome"] } }]`
- CI installs only chromium: `npx playwright install --with-deps chromium`
- E2E job opt-in; local runs use chromium by default
- Vitest runs in jsdom (cross-browser DOM semantics; not full browser)
- Kernel tests run in Node 24 (platform-agnostic)

## Recommended Matrix (for approval)
| Browser | Support Level | Rationale | CI Cost |
|---|---|---|---|
| Chromium | Required (baseline) | Primary target; covers most users | Low (current) |
| Firefox | Optional/cadence TBD | Cross-engine validation; CSS/JS differences rare in this app | Medium (+install time) |
| WebKit (Safari) | Optional/cadence TBD | iOS/macOS coverage; stricter CSP/clipboard behaviors | Higher (install deps) |

## Proposed Cadence (if expanded)
- PR: Chromium only (keep fast)
- Nightly/release or workflow_dispatch with all browsers (approved runs only)
- Pin Playwright/browser versions (current: @playwright/test ^1.63.0, browsers installed in CI)

## Recommendations
1. Keep Chromium as required baseline for PRs
2. Add Firefox/WebKit only when explicitly approved and environment ready (don’t slow PR gates)
3. Document matrix in docs/testing.md after approval
4. Pin versions explicitly in CI (already using npx playwright install)

**Status:** Baseline Chromium only. Expansion needs approval on cadence/CI cost. No changes made.
