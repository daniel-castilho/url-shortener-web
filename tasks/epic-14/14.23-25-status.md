## 14.23 — Bearer E2E Journey (API-level)
- Login via `POST /api/v1/auth/login` (JSON) → asserts HTTP 200, extracts `token`
- Shorten via `POST /api/v1/urls` with `Authorization: Bearer <token>` → asserts HTTP 201, response has `id` and `shortUrl`
- List via `GET /api/v1/urls` with Bearer token → asserts HTTP 200, response has `items` array
- All calls use `curl --fail` equivalent (custom helper) with explicit status + JSON field validation

**Verification command (local):**
```bash
API_BASE_URL=http://localhost:8080
# Login
body=$(mktemp)
status=$(curl -sS -o "$body" -w '%{http_code}' -X POST "$API_BASE_URL/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","password":"password123"}')
[[ "$status" == "200" ]] || { echo "Login expected 200, got $status"; exit 1; }
TOKEN=$(python3 - "$body" <<'PY'
import json, sys; print(json.load(open(sys.argv[1]))["token"])
PY
)
# Shorten
body=$(mktemp)
status=$(curl -sS -o "$body" -w '%{http_code}' -X POST "$API_BASE_URL/api/v1/urls" \
  -H "Content-Type: application/json" -H "Authorization: Bearer $TOKEN" \
  -d '{"originalUrl":"https://e2e.example.com/x","customAlias":"api-e2e-test"}')
[[ "$status" == "201" ]] || { echo "Shorten expected 201, got $status"; exit 1; }
python3 - "$body" <<'PY'
import json, sys; d=json.load(open(sys.argv[1])); assert d.get("id") and d.get("shortUrl")
PY
# List
body=$(mktemp)
status=$(curl -sS -o "$body" -w '%{http_code}' -X GET "$API_BASE_URL/api/v1/urls" \
  -H "Authorization: Bearer $TOKEN")
[[ "$status" == "200" ]] || { echo "List expected 200, got $status"; exit 1; }
python3 - "$body" <<'PY'
import json, sys; d=json.load(open(sys.argv[1])); assert isinstance(d.get("items"), list)
PY
```

## 14.24 — Cookie E2E Journey (API-level)
- Login with `-c cookie_jar` (sets `access_token`/`refresh_token` cookies per backend contract) → asserts HTTP 200, validates both cookies present in jar
- Shorten via `POST /api/v1/urls` with `-b cookie_jar` (no `Authorization` header) → asserts HTTP 201, response has `id`
- Refresh via `POST /api/v1/auth/refresh` with cookie jar → asserts HTTP 200, response has `token` and `refreshToken`
- No token/refresh bodies printed to logs

**Verification:**
```bash
API_BASE_URL=http://localhost:8080
COOKIE_JAR=$(mktemp)

# Cookie login
body=$(mktemp)
status=$(curl -sS -o "$body" -w '%{http_code}' -X POST "$API_BASE_URL/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","password":"password123"}' \
  -c "$COOKIE_JAR" -b "$COOKIE_JAR")
[[ "$status" == "200" ]] || { echo "Cookie login expected 200, got $status"; exit 1; }
grep -q "access_token" "$COOKIE_JAR" && grep -q "refresh_token" "$COOKIE_JAR" || { echo "Cookies not set"; exit 1; }

# Cookie shorten
body=$(mktemp)
status=$(curl -sS -o "$body" -w '%{http_code}' -X POST "$API_BASE_URL/api/v1/urls" \
  -H "Content-Type: application/json" \
  -d '{"originalUrl":"https://cookie.example.com/y"}' \
  -b "$COOKIE_JAR")
[[ "$status" == "201" ]] || { echo "Cookie shorten expected 201, got $status"; exit 1; }
python3 - "$body" <<'PY'
import json, sys; d=json.load(open(sys.argv[1])); assert d.get("id")
PY

# Refresh
body=$(mktemp)
status=$(curl -sS -o "$body" -w '%{http_code}' -X POST "$API_BASE_URL/api/v1/auth/refresh" \
  -b "$COOKIE_JAR")
[[ "$status" == "200" ]] || { echo "Refresh expected 200, got $status"; exit 1; }
python3 - "$body" <<'PY'
import json, sys; d=json.load(open(sys.argv[1])); assert d.get("token") and d.get("refreshToken")
PY
```
